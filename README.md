# 여행 일정 GitHub Pages

정적 HTML, CSS, JavaScript로 만든 여행 일정 모음입니다.

- 홈: `https://kianms10310.github.io/`
- 제주도 여행: `https://kianms10310.github.io/jeju-2026/`

제주도 페이지는 한국 시간(`Asia/Seoul`) 기준으로 접속한 날짜의 일정을 자동 선택합니다. 여행 시작 전에는 첫날, 여행 종료 후에는 마지막 날을 보여줍니다. 날짜 탭을 눌러 다른 날짜를 볼 수도 있습니다.

각 장소의 **주소 복사**, **Google 지도 열기**, **완료**, **못함**을 지원합니다. 못함으로 표시한 일정은 이후 날짜에도 표시되며, 완료 처리할 수 있습니다. 상태는 현재 기기의 브라우저 `localStorage`에 저장되므로 다른 기기와 동기화되지는 않습니다.

## 일정 수정

`jeju-2026/itinerary.js`에서 `days`의 날짜별 `items`를 수정하세요. 현재는 **11월 12일 1일차만** 입력되어 있습니다. 13~15일의 계획이 정해지면 같은 형식으로 날짜를 추가하면 됩니다. 각 일정의 `id`는 기존 상태 저장에 사용되므로 수정할 때 유지하세요.

새 여행을 만들려면 `jeju-2026/` 폴더를 복사하여 새 폴더를 만들고, `itinerary.js`의 `id`, 날짜, 일정을 수정한 뒤 홈 `index.html`에 링크를 추가하세요.

> 이 저장소와 GitHub Pages는 공개됩니다. 예약번호, 개인 연락처, 결제 정보 등은 일정 파일에 넣지 마세요.

## 게시

GitHub 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)**를 선택하면 됩니다.
